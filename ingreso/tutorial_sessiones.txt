¡Claro que sí! Te puedo ayudar a implementar un sistema para controlar la sesión en tu sitio web con PHP y JavaScript, y cerrar la sesión automáticamente después de 10 minutos de inactividad.

Planteamiento:

    Establecer tiempo de inicio de sesión: Al iniciar sesión, se almacenará la hora actual en una variable de sesión.
    Actualizar tiempo de actividad: En cada interacción del usuario (clic, movimiento del mouse, etc.), se actualizará la variable de sesión con la hora actual.
    Verificar inactividad: Cada vez que se cargue una página o se realice una acción, se comparará la hora actual con la última hora de actividad almacenada en la sesión.
    Cerrar sesión por inactividad: Si la diferencia entre la hora actual y la última hora de actividad es mayor a 10 minutos, se cerrará la sesión, se eliminarán las variables de sesión y se notificará al usuario.

Implementación:

1. Almacenar tiempo de inicio de sesión (PHP):
PHP

<?php
session_start();

// Al iniciar sesión, guardar la hora actual en la variable de sesión 'last_activity'
$_SESSION['last_activity'] = time();
?>

JavaScript

$(document).ready(function() {
    // Función para actualizar la variable 'last_activity'

        $.ajax({
            url: 'update_last_activity.php', // Script PHP para actualizar la hora
            success: function() {
                console.log('Actividad actualizada');
            }
        });
    }

    // Actualizar 'last_activity' cada X segundos (ej: 1 minuto = 60000 ms)
    setInterval(updateLastActivity, 60000);

    // Actualizar 'last_activity' en cada interacción del usuario (clic, movimiento del mouse)
    $(document).on('click mousemove', updateLastActivity);

3. Crear script update_last_activity.php:
PHP

<?php
session_start();

// Actualizar la variable de sesión 'last_activity' con la hora actual
$_SESSION['last_activity'] = time();
?>

Usa el código con precaución.

4. Verificar inactividad y cerrar sesión (PHP):
PHP

<?php
session_start();

// Tiempo límite de inactividad (en segundos, ej: 10 minutos = 600 segundos)
$inactivity_limit = 600;

// Obtener la última hora de actividad
$last_activity = isset($_SESSION['last_activity']) ? $_SESSION['last_activity'] : time();

// Calcular el tiempo transcurrido desde la última actividad
$elapsed_time = time() - $last_activity;

// Si el tiempo transcurrido supera el límite, cerrar la sesión
if ($elapsed_time > $inactivity_limit) {
    session_unset();
    session_destroy();
    
    // Redireccionar a la página de login o mostrar mensaje de sesión expirada
    header('Location: login.php');
    exit;
}
?>

Usa el código con precaución.

5. Integrar la verificación en cada página:
PHP

<?php
include('verificar_inactividad.php'); // Incluir script de verificación en cada página
?>

Consideraciones adicionales:

    Notificación al usuario: Puedes mostrar un mensaje emergente o redirigir al usuario a la página de login cuando la sesión se cierre por inactividad.
    Ajustar el tiempo de inactividad: El valor de $inactivity_limit en el script PHP define el tiempo después del cual se cierra la sesión. Puedes modificarlo según tus necesidades.
    Almacenamiento en base de datos: Si necesitas un registro más persistente de las sesiones, puedes almacenar las variables de sesión en una base de datos en lugar de usar solo variables de sesión del lado del servidor.
